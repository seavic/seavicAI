# Brand Assets

Place the approved Option A Structured Intelligence logo exports in `public/brand/` when available.

Launch rule:
- Use only approved light, dark, one-color, icon-only, and favicon-safe files.
- Do not redraw, distort, or reconstruct the Structured Intelligence mark from memory or written specifications.
- The current site uses a text wordmark fallback until approved assets are supplied.

## Typography Usage

The current staging build uses the approved fallback stack available in code: `Inter, Arial, Helvetica, sans-serif`.

Until a fuller brand typography guideline is supplied, use this scale:
- Homepage hero: large executive headline.
- Service-page hero: compact hero headline scale for better page balance.
- Section headings: standard scale for short section titles; compact scale when the heading is long or paired with a long explanatory paragraph.
- Body copy: standard paragraph scale with consistent line height across all pages.

Do not introduce page-specific fonts or oversized service-page headings without updating this note and the shared components.
