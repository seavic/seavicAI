# Contributing

This repository follows the SeaVic website governance workflow.

1. Draft changes in a branch.
2. Check public copy against `CONTENT_GOVERNANCE.md`.
3. Run `npm run build` and `npm run lint`.
4. Request founder review for public positioning, claims, legal text, partner language, and gated features.
5. Merge only through the protected `main` branch review process.

Do not commit secrets, unpublished sensitive partner material, client names, pricing, or unsupported claims.
